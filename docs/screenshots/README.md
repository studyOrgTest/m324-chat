# Screenshots

Place the Uptime Kuma screenshots referenced by [`DOKUMENTATION.md`](../../DOKUMENTATION.md)
in this folder, using exactly these file names:

| File name | What it should show |
|---|---|
| `uptime-kuma-monitor.png` | The configured HTTP(s) monitor on `/healthcheck` (status "Up") |
| `uptime-kuma-notification.png` | The ntfy notifier — a test alert from Uptime Kuma received on ntfy.sh |
| `uptime-kuma-dashboard.png` | The Uptime Kuma dashboard with the monitor running |

These are produced once Uptime Kuma is set up — see `SETUP.md`, section "Monitoring".
